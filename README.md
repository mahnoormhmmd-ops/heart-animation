💖 Heart Trail

The heart animation website is a smiple interactive web page made with HTML5, CSS3 and Javascript.
As the user moves the cursor across the screen, hearts of different sizes and colors appear and they move upward and fade after a few moments.


Live Demo: https://heart-animation-website.vercel.app/


This project uses HTML5 for its structure, CSS3 for styling and animations of heart, and Java Script for detecting the cursor movements, generating hearts, and them removing them smoothly after a while. No external frameworks or libraries are used.


The application works by detecting the cursor movement with the help of mousemove function. When movement is detected, java creates a new heart with a random size at that position and ten adds the floating animation to it, and then makes it fade away after some time, which keeps the page clutter free and makes space for more hearts.

While making the project, I learned to work with mouse events, DOM manipulation, making animations with keyframes, element creation at specific event, managing timed events using setTimeout function.

Future improvements include touch support for mobile devices, additional particle effects, and different animation styles.
